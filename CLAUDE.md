# CLAUDE.md

Gerador de miniaturas para batalhas de rima. Next.js 13 (App Router) + Tailwind,
100% client-side: a imagem nunca sai do navegador. Textos da interface em
português.

## Comandos

```bash
yarn dev      # servidor local em http://localhost:3000
yarn build    # build de produção
yarn lint     # eslint
```

## Preferências de trabalho

- **Commits atômicos.** Um commit por mudança coesa, durante o desenvolvimento —
  não um commit gigante no final.
- **Changelog.** Se a tarefa for uma feature ou bugfix, me peça o texto para o
  changelog (`src/lib/releaseNotes.ts`) ou a permissão explícita para ignorá-lo.
  Não escreva o texto por conta própria.
- **Push.** Ao finalizar a tarefa, faça push direto para `origin/main`.
